О сервисе

Некрополь

Некрополь объединяет сайт управления мирами Minecraft, limbo-авторизацию и серверные инструменты в одном кабинете.

Через сервис можно создавать миры, просматривать их состояние, управлять доступом и менять данные учетной записи без выхода из текущего окна.

Связь с Minecraft

Как работает привязка

Привязка определяет, какой Minecraft-аккаунт имеет право использовать твои сервера на сайте.

Как менять привязку 1. Для автоматической привязки зайди на limbo-сервер через нужный Minecraft-аккаунт и выполни `/login <username> <password>` 2. Для ручной перепривязки открой личный кабинет по иконке профиля сверху 3. Для отвязки внутри игры выполни `/unlinkaccount` в консоли limbo-сервера
