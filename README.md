Сборка проекта происходит в корне через build.bat, затем можно запускать через run.bat непосредственно dev версию, либо же можно собрать отдельный готовый к запуску проект через deploy.bat, который соберет его в папку dev/prod/... Прод версию можно будет запустить через run.bat на винде либо через docker-compose где угодно
